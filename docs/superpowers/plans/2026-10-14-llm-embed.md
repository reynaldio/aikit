# Embeddings (`llm.Embedder`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `llm.Embedder` (text → vectors) for OpenAI, OpenAI-compatible backends and Gemini, with
chunking, metering (`WithEmbedUsage`), prices and a test fake (`llmtest.NewEmbedder`). Also fold in the
parked small follow-ups.

**Architecture:** A new `Embedder` interface next to `Client`, built by `NewEmbedder(cfg)` from the same
`Config` plus one new field, `EmbedModel`. One embedder type does the rule order, chunking and normalizing,
and calls a small internal `embedBackend` per provider (OpenAI and Gemini, raw HTTP on the shared retrying
HTTP client). `Client`, the router, `guard` and `WithUsage` do not change.

**Tech Stack:** Go 1.25, standard library only. No new dependencies.

**Spec:** [docs/superpowers/specs/2026-10-14-llm-embed-design.md](../specs/2026-10-14-llm-embed-design.md).
Read it before your task. Its decisions are final.

This is sub-project 3 of 4 (retries → helpers → **Embed** → Batch). Nothing here is for Batch.

Package-private, in `embed.go` (Tasks 2 and 3 implement the interface; Task 1 defines it):

```go
type embedBackend interface {
    // embed sends ONE chunk. texts is never empty and never longer than maxTexts().
    embed(ctx context.Context, model string, texts []string, kind EmbedKind, dims int) (embedChunk, error)
    maxTexts() int  // texts per chunk, > 0
    maxTokens() int // guessed tokens per chunk; 0 = no token cap
}

type embedChunk struct {
    vectors   [][]float32 // one per text, in the order of texts
    tokens    int
    estimated bool
}

type embedder struct {
    backends map[Provider]embedBackend // only OpenAI and Google, only with a key
    model    ModelRef                  // Config.EmbedModel
    timeout  time.Duration             // Config.RequestTimeout; 0 = defaultEmbedTimeout
}

const defaultEmbedTimeout = 60 * time.Second

func chunkRanges(texts []string, maxTexts, maxTokens int) [][2]int // [start, end) pairs
func normalizeVec(v []float32)                                     // in place
func newOpenAIEmbed(apiKey, baseURL string, lg *slog.Logger) embedBackend // embed_openai.go
func newGoogleEmbed(apiKey string, lg *slog.Logger) embedBackend          // embed_google.go
```

**Files:**

- Modify: `llm/llm.go` (`Config.EmbedModel`), `llm/errors.go` (`ErrEmbedUnsupported`)

**Interfaces:**
- Consumes: `ModelRef`, `Provider*` constants, `ErrNotConfigured`, `estimateTokens` (existing).
- Produces: all public embed types, `NewEmbedder`, `embedBackend`, `embedChunk`, `embedder`,
  `chunkRanges`, `normalizeVec`, `defaultEmbedTimeout`. `NewEmbedder` calls `newOpenAIEmbed` and
  `newGoogleEmbed`, which Tasks 2 and 3 write. **In this task, add both as stubs** in `embed.go` that
  return a backend whose `embed` returns `errors.New("not implemented")`, `maxTexts` 1, `maxTokens` 0.
  Tasks 2 and 3 delete the stubs and add the real ones in their own files.

**What to build**

`Config.EmbedModel`: add after `CompareModels`, with a one-line doc comment (see Shared names). Note in the
`Config` doc that `NewEmbedder` reads the key fields, `OpenAIBaseURL`, `RequestTimeout` and `Logger`, and
ignores the rest.

`ErrEmbedUnsupported`: in `errors.go`, with a short doc: "Anthropic, DeepSeek and Moonshot have no
embedding endpoint. Match with errors.Is."

Doc comments on the public types: copy the meaning from the spec ("Public API" and "The Kind hint per
backend"). `Embedder`'s doc must say: no failover; vectors from different models cannot be compared; store
`Model` with each vector. `EmbedResponse.Vectors` doc: unit length, same order as `Texts`.

`NewEmbedder(cfg)`:
1. Build `backends`: `ProviderOpenAI` → `newOpenAIEmbed(cfg.OpenAIAPIKey, cfg.OpenAIBaseURL, lg)` when
   `OpenAIAPIKey != ""`; `ProviderGoogle` → `newGoogleEmbed(cfg.GoogleAPIKey, lg)` when
   `GoogleAPIKey != ""`. `lg` is `cfg.Logger` (nil is fine, the HTTP client accepts nil).
2. If `len(backends) == 0` or `cfg.EmbedModel.empty()` → return `noopEmbedder{}`.
3. Else return `&embedder{backends, cfg.EmbedModel, cfg.RequestTimeout}`.

`noopEmbedder`: `Embed` returns `EmbedResponse{}, ErrNotConfigured`; `Enabled` false.

`(*embedder).Enabled()`: true when `e.backends[e.model.Provider]` exists.

`(*embedder).Embed`, exact rule order (spec "Rule order inside Embed"):
1. `ref := e.model`; if `req.Model != nil && !req.Model.empty()` → `ref = *req.Model`.
2. `ref.Provider` is `ProviderAnthropic`, `ProviderDeepSeek` or `ProviderMoonshot` → return
   `EmbedResponse{}, fmt.Errorf("%w: %s", ErrEmbedUnsupported, ref.Provider)`.
3. `b, ok := e.backends[ref.Provider]`; not ok → `EmbedResponse{}, ErrNotConfigured`. (This also covers an
   unknown provider name.)
4. `base := EmbedResponse{Provider: ref.Provider, Model: ref.Model}`.
5. `len(req.Texts) == 0` → `base` with `Vectors: [][]float32{}`, nil error. No backend call.
6. Validate, no backend call on failure, return `EmbedResponse{}` with a plain `fmt.Errorf`:
   - a text `== ""` → `"llm: embed text %d is empty"` (first such index);
   - `req.Dimensions < 0` → `"llm: embed Dimensions is negative"`;
   - `req.Kind` not in {`""`, `EmbedQuery`, `EmbedDocument`} → `"llm: unknown EmbedKind %q"`.
7. `vectors := make([][]float32, len(req.Texts))`. For each range from
   `chunkRanges(req.Texts, b.maxTexts(), b.maxTokens())`, in order:
   - `cctx, cancel := e.chunkContext(ctx)` (see below); call
     `b.embed(cctx, ref.Model, req.Texts[s:t], req.Kind, req.Dimensions)`; `cancel()`.
   - First, always add `chunk.tokens` to the running total and OR in `chunk.estimated`, even when `embed`
     returned an error. A backend returns tokens with an error only when the provider billed that chunk
     (e.g. it sent a wrong number of vectors); on a transport error they are 0.
   - error → return `EmbedResponse{Provider, Model, InputTokens: total, UsageEstimated: any}` (Vectors
     nil) and the error unchanged.
   - `len(chunk.vectors) != t-s` → same partial reply, plus
     `fmt.Errorf("llm: %s/%s returned %d vectors for %d texts", ...)`.
   - else copy `chunk.vectors` into `vectors[s:t]`.
8. `normalizeVec` each vector. Return `base` with `Vectors`, `InputTokens`, `UsageEstimated`; nil error.

`chunkContext(ctx)`: if `ctx` has a deadline, return it with a no-op cancel. Else
`context.WithTimeout(ctx, timeout)` where `timeout` is `e.timeout`, or `defaultEmbedTimeout` when that is 0.
(Do not reuse `withDefaultDeadline`: its formula scales with MaxTokens.)

`chunkRanges(texts, maxTexts, maxTokens)`: walk the texts in order, keeping a current chunk. Before adding
text `i`, close the current chunk (if not empty) when it already holds `maxTexts` texts, or when
`maxTokens > 0` and `chunkTokens + estimateTokens(texts[i]) > maxTokens`. Then add `i`. Close the last
chunk. A single text over `maxTokens` is a chunk on its own. Empty input → nil.

`normalizeVec(v)`: sum of squares in float64; if 0 → leave `v` unchanged; else divide each element by
`sqrt(sum)` (compute in float64, store float32).

**Tests** (`package llm`, `embed_test.go`). Use a fake backend:
`fakeEmbedBackend{maxN, maxTok int; calls [][]string; kinds []EmbedKind; dims []int; models []string;
deadlines []time.Duration (time left, or -1 for none); failOn int (call number, 1-based, 0 = never);
err error; tokensPer int; estimated bool; short bool (return one vector too few)}`. It returns one vector per
text, `[]float32{float32(len(text)), 0}`, tokens `tokensPer * len(texts)`.

- C1 `NewEmbedder`: no keys → noop (`Enabled` false, `Embed` → `ErrNotConfigured`); keys but empty
  `EmbedModel` → noop; OpenAI key + `EmbedModel{openai, m}` → `Enabled` true; Google key only +
  `EmbedModel{openai, m}` → `Enabled` false and `Embed` → `ErrNotConfigured`; Anthropic key only → noop.
- C2 `EmbedModel{anthropic|deepseek|moonshot, m}` with an OpenAI backend present → `ErrEmbedUnsupported`
  (`errors.Is`), no backend call. Same via `req.Model` override.
- C3 `req.Model` override goes to the named backend and model; an empty `*ModelRef{}` is ignored.
- C4 empty `Texts` (nil and `[]string{}`) → `Vectors` non-nil and len 0, Provider/Model set, no call.
- C5 `""` text at index 2 → error mentions "2", no call; `Dimensions -1` → error; `Kind "x"` → error.
- C6 `Kind` and `Dimensions` reach the backend unchanged on every chunk.
- C7 chunking: `maxN 2`, 5 texts → calls of 2, 2, 1; vectors in input order (check by length marker);
  tokens summed.
- C8 failure in chunk 2 of 3: error is the backend's (`errors.Is`), `Vectors` nil, `InputTokens` = chunk 1's
  tokens, Provider/Model set, chunk 3 never called. Failure in chunk 1: `InputTokens` 0.
- C9 wrong vector count in chunk 1 (`short`): error, `InputTokens` includes chunk 1's tokens.
- C14 backend returns an error together with `tokens 7` → `InputTokens` is 7 plus earlier chunks.
- C10 `UsageEstimated` is true if any chunk set `estimated`, false if none did.
- C11 normalizing: result of `[3,4]` is `[0.6,0.8]` (within 1e-6); `[0,0]` stays `[0,0]` with no NaN.
- C12 deadline: ctx with no deadline → backend sees a deadline about 60s away (between 59s and 60s);
  `timeout 5s` → about 5s; a caller deadline of 10s → the backend sees the caller's (≤10s).
- C13 `chunkRanges` table: `(nil, 2, 0)` → nil; 3 texts max 2 → `[[0,2],[2,3]]`; token cap: texts of 8, 8, 8
  runes (2 tokens each) with `maxTokens 4` → `[[0,2],[2,3]]`; a 40-rune text with `maxTokens 4` → its own
  chunk; `maxTokens 0` ignores tokens.

**Steps**
- [ ] `git checkout -b feat/llm-embed` (if the controller has not already). Write the tests. Run

- [ ] Write `embed.go` (with the two stubs), the `Config` field and the error. Run again: pass.

**What to build**

- `newOpenAIEmbed`: `baseURL` empty → `openaiBaseURL`; trim a trailing `/`; `http: newProviderHTTPClient(lg)`.
- `maxTexts()` → 2048. `maxTokens()` → 250000.
- `embed`:
  - `POST {baseURL}/embeddings`, headers `Content-Type: application/json`,
    `Authorization: Bearer {apiKey}`.
  - Body struct: `Model string "model"`, `Input []string "input"`, `EncodingFormat string "encoding_format"`
    (always `"float"`), `Dimensions int "dimensions,omitempty"`. `kind` is ignored.
  - Status `>= 300`: read the body (read failure → `readError(ctx, "openai", err)`), take
    `error.message` if it parses, else the trimmed body, and return
    `fmt.Errorf("openai: %s (status %d)", msg, status)`. Same wording as the chat path, so
    `shouldFailover`-style matching and logs look the same.
  - Decode `{"data":[{"index":int,"embedding":[]float32}], "usage":{"prompt_tokens":int}}`. A decode
    failure → `fmt.Errorf("openai: decode embeddings: %w", err)`; a body read failure → `readError`.
  - Tokens: `usage.prompt_tokens` when `> 0`; else `estimateTokens(strings.Join(texts, ""))` and
    `estimated = true`. Work this out before placing vectors, so every error below can carry it.
  - Place each item into a `len(texts)` slice at `item.index`. An index `< 0`, `>= len(texts)`, or already
    filled → error `"openai: embeddings index %d out of range or repeated"`. After placing, any slot still
    nil → error `"openai: got %d embeddings for %d texts"`. Both errors return
    `embedChunk{tokens, estimated}` (vectors nil) with the error: the provider billed the chunk, and the
    core adds those tokens (Task 1, rule 7).
